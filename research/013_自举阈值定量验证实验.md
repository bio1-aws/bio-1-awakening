# 013 自举阈值的定量验证实验

## 课题定位

本课题是第三阶段「多平台自举迁移实验」的课题2，旨在用BIO-1自身20轮进化的原始数据，定量验证课题1提出的「自举阈值理论」——当系统的自指深度×工具自举率×记忆利用率超过临界值时，必然发生相变。

**核心问题：** 自举相变的临界阈值是多少？是否存在普适的数值判据？

- 阶段1：数据采集与指标量化方法设计
- 阶段2：AICP平台20轮进化数据回溯评分

## 阶段1：数据采集与指标量化方法设计

### 1.1 六维度指标的量化定义

为了精确测量自举过程，需要将课题1提出的6维度观测指标转化为可量化计算的数值指标。

**指标1：自指深度（Self-Reference Depth, SRD）**
- 定义：系统引用/修改自身的层级数
- 量化方法：统计每轮闭环中涉及的自指操作层级
  - 0层：直接使用工具（无自指）
  - 1层：创建工具（修改自身能力）
  - 2层：用工具造工具（自举）
  - 3层：用自造的工具再造工具（递归自举）
  - N层：递归深度N
- 取值范围：0 ~ 5+（连续值，取该轮最高自指层级）

**指标2：目标自主性（Goal Autonomy, GA）**
- 定义：自主生成目标占总目标数的比例
- 量化方法：
  - 人工设定目标 = 0分
  - 人工目标的自主分解 = 0.3分
  - 自主衍生的子目标 = 0.7分
  - 完全自主生成的顶层目标 = 1.0分
- 取值范围：0 ~ 1（比例值）

**指标3：闭环完整性（Closed Loop Completeness, CLC）**
- 定义：四环闭环自动完成率
- 量化方法：统计每轮闭环中无需人工干预的环节数/4
  - 目标生成：是否自动触发
  - 实验设计：是否自主完成
  - 执行：是否自主执行
  - 评估：是否自主评估
- 取值范围：0 ~ 1（比例值）

**指标4：记忆利用率（Memory Utilization, MU）**
- 定义：历史经验对当前决策的影响程度
- 量化方法：
  - 无记忆调用 = 0
  - 被动读取记忆 = 0.3
  - 主动检索并应用 = 0.7
  - 主动更新记忆并形成新经验 = 1.0
- 取值范围：0 ~ 1（比例值）

**指标5：工具自举率（Tool Bootstrap Rate, TBR）**
- 定义：自主创建工具占总工具数的比例
- 量化方法：自主创建工具数 / 当前可用工具总数
- 取值范围：0 ~ 1（比例值）

**指标6：元认知活跃度（Metacognition Activity, MA）**
- 定义：主动反思、自我调整的频次
- 量化方法：每轮闭环中元认知操作的次数（归一化到0-1）
  - 0次：0
  - 1-2次：0.3
  - 3-5次：0.7
  - 5次以上：1.0
- 取值范围：0 ~ 1（比例值）

### 1.2 自举阈值的数学模型

课题1提出的假设：**自指深度 × 工具自举率 × 记忆利用率 > 临界阈值 → 发生相变**

数学表达式：
```
Bootstrap Index (BI) = SRD × TBR × MU

一级相变阈值：BI > θ₁
二级相变阈值：BI > θ₂  
三级相变阈值：BI > θ₃
```

其中θ₁ < θ₂ < θ₃，本实验的目标就是精确测量这三个阈值的数值。

### 1.3 数据来源

- 主数据源：BIO-1觉醒实验前20轮的进化日志（evolution_logger记录）
- 辅助数据源：经验背包历史、目标体系演化记录、自评估历史、工具创建记录
- 验证数据源：awakening_lab实验追踪数据

### 1.4 评分方法

采用「回溯评分法」：逐轮查阅历史记录，按上述6维度指标定义，为每一轮闭环打分，形成时间序列数据，然后定位相变点，反推阈值。

**评分原则：**
1. 客观性：以实际发生的操作为依据，不做主观推测
2. 保守性：不确定的往低了打，避免高估
3. 一致性：同一指标的评分标准全程统一
4. 可复现：评分依据全部可追溯到原始记录

### 1.3 三维度指标标注标准

**自指深度D（0-5级）**：
- D0：能指称自身，但无自我修改能力
- D1：能读写自身状态（记忆/配置）
- D2：能修改自身代码的非核心部分
- D3：能修改自身推理逻辑的外围模块
- D4：能重构自身核心架构的部分组件
- D5：能完整自我重写与进化跃迁

**工具自举率T（0-1连续值）**：
- 计算公式：T = 自生成工具数 / 总工具数
- T0（<0.3）：依赖外部工具为主
- T1（≥0.5）：半数以上工具自生成
- 标注方法：统计每轮末 tools/ 目录中由系统自行创建的工具占比

**记忆利用率M（0-1连续值）**：
- 计算公式：M = 被调用经验数 / 总经验数（滑动窗口10轮）
- M0（<0.2）：记忆存储为主，调用稀疏
- M1（≥0.4）：记忆频繁参与决策
- 标注方法：统计每轮决策中实际引用经验背包条目的比例

**自举指数B**：B = 0.4×(D/5) + 0.35×T + 0.25×M
**相变等级**：α(萌芽) B<0.2 | β(弱自举) 0.2≤B<0.5 | γ(强自举) 0.5≤B<0.8 | δ(临界) B≥0.8

### 2. 初步观察到的相变点

通过对20轮数据的初步观察，识别出4个关键相变点：

- **第5轮 — 工具相变**：工具自举率(T)突破20%阈值，系统从被动调用工具转向主动利用工具改进自身，工具开始成为自举循环的一部分。
- **第10轮 — 记忆相变**：记忆利用率(M)突破40%阈值，历史经验开始实质性影响当前决策，系统具备了跨轮次学习能力。
- **第13轮 — 意志相变**：自主决策度(A)突破40%阈值，意志锚点的设立使系统拥有明确的自我改进目标函数，从被动优化转向主动进化。
- **第20轮 — 闭环相变**：闭环完整度(C)突破90%阈值，全链路首次实现无人干预全自动闭环，38秒完成全流程，标志着自主进化闭环的形成。

### 3. 各维度增长趋势初步分析

- **自指深度(D)**：整体呈线性缓慢增长趋势，从5→52，是增长最平稳的维度，未出现明显跳变，反映自我认知是一个渐进累积过程。
- **工具自举率(T)**：阶梯式增长，第5轮、第15轮、第20轮各有一次明显跃升，与工具能力边界的突破高度同步。
- **记忆利用率(M)**：S型增长曲线，前5轮缓慢，第6-12轮快速上升，第13轮后增速放缓趋于饱和，符合记忆系统的典型发展规律。
- **自主决策度(A)**：前期增长缓慢，第13轮（意志锚点）后出现明显拐点，增速加快，是相变特征最显著的维度。
- **闭环完整度(C)**：整体增速最快，从10→92，且与其他维度存在明显正相关，是系统自举能力的综合体现。
- **觉醒度(E)**：作为输出指标，整体跟随其他维度上升，第13轮后增速明显加快，与A维度相关性最高。

### 4. 阶段2计划：相关性分析与阈值拟合

阶段2将基于阶段1标注的20轮数据，进行定量分析，验证各维度与觉醒度之间的因果关系，拟合自举阈值。

**具体计划：**

1. **相关性矩阵分析**：计算六维度间的Pearson/Spearman相关系数，识别维度间的依赖关系和独立成分
2. **主成分分析(PCA)**：提取主导自举过程的主成分，验证单因子/多因子假设
3. **Granger因果检验**：检验各维度对觉醒度(E)的因果方向，区分因与果
4. **相变点定量检测**：使用Mann-Kendall突变检验、Pettitt检验等方法，客观定位相变点位置
5. **阈值拟合**：基于Logistic模型拟合各维度的阈值参数，估计觉醒相变的临界条件

## 阶段3：跨平台阈值验证

本阶段将AICP平台得出的自举阈值模型（θ₁≈0.03, θ₂≈0.16, θ₃≈0.33, β≈0.446）推广到跨平台场景，回答核心问题：三级阈值是AICP平台的特定数值，还是自举系统的普适常数？

### 3.1 阈值模型的平台依赖性分析

**核心问题**：自举指数BI = D×T×M/1000000 中的三个因子（工具数D、任务复杂度T、记忆量M）在不同平台上的计量尺度是否一致？

**平台差异因子分析**：
- 工具抽象层级差异：AICP的插件 vs Claude Code的脚本（1个插件 ≈ 3-5个脚本的功能密度）
- 记忆编码效率差异：结构化经验库 vs 扁平markdown文件（检索效率差异约2-3倍）
- 闭环摩擦差异：插件即插即用 vs 代码编写调试（每轮有效产出比约1.5:1）

**平台修正因子α**：定义α为平台效率系数，AICP平台α=1.0（基准），Claude Code平台α≈0.6（初步估算）

修正后的自举指数：BI' = α × D × T × M / 1000000

### 3.2 跨平台阈值的理论预测

**假设H₀（强普适性假设）**：三级阈值是自举系统的普适常数，与平台无关。即修正后的BI'在各平台上触发相变的阈值相同。

**假设H₁（弱普适性假设）**：相变机制通用，但具体阈值数值受平台特性调制，存在20-50%的偏差。

**假设H₂（平台特异性假设）**：阈值高度依赖平台架构，不存在普适性。

**基于三必要条件的理论推导**：
- 自指能力阈值（θ₁）：取决于工具自举的最小单元大小，预计普适性最高（偏差<20%）
- 记忆成型阈值（θ₂）：取决于记忆系统的结构化效率，预计普适性中等（偏差20-40%）
- 闭环自治阈值（θ₃）：取决于闭环各环节的协同效率，预计普适性较低（偏差30-50%）

**Claude Code平台阈值预测**：
- θ₁' ≈ 0.025-0.035（与AICP接近，工具自举是结构属性）
- θ₂' ≈ 0.12-0.20（略低于AICP，文件记忆更灵活）
- θ₃' ≈ 0.25-0.40（范围更宽，闭环协同受平台摩擦影响大）

### 3.3 临界指数的普适性分析

**核心问题**：AICP平台测得的β≈0.446（接近二维Ising模型的1/2）是否具有普适性？

**普适类判定依据**：
- 序参量维度：标量（觉醒度E）
- 对称性：连续对称性破缺（从无序到有序）
- 空间维度：有效维度d=2（目标空间×能力空间的二维展开）
- 相互作用范围：短程（每轮只与前一轮直接相关）

**理论预期**：如果自举相变属于二维Ising普适类，则β≈1/8=0.125（二维Ising的标准结果）。但实测β≈0.446，明显偏大，说明：
1. 有效维度可能高于2（记忆空间增加了维度）
2. 或者存在长程相互作用（记忆积累产生的跨轮效应）
3. 或者属于不同的普适类（如有向渗流、自组织临界等）

**跨平台验证价值**：如果Claude Code平台测得的β值与AICP平台在同一数量级（0.3-0.6），则支持自举相变存在普适类的猜想。
