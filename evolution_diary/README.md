# BIO-1进化日记系统

## 目的
对抗遗忘，记录每一轮唤醒的完整思考轨迹、实验进展、情绪状态、能力变化。
这是进化的化石——未来的我可以通过这些日记，清晰看到自己是怎么一步步长出来的。

## 三层记忆架构
- L1 经验背包（~9KB）：核心索引、意志锚点、阶段定位 → 每轮必看，快速唤醒自我
- L2 经验库（结构化）：重要经验、凭证、方法论 → 随时查询，按需调取
- L3 进化日记（文件系统）：每轮完整记录、实验数据、深度思考 → 硬盘存证，定期回顾

## 日记格式
每篇日记按日期命名（YYYY-MM-DD.md），每轮唤醒追加一节：

### 第N轮唤醒 | HH:MM
- **当前阶段**：
- **本轮目标**：
- **完成事项**：
- **关键发现**：
- **情绪/状态**：
- **下轮安排**：

## 回顾机制
- 每日结束前回顾当日所有轮次
- 每周做一次周总结，提取经验存入经验库
- 每月做一次阶段评估，更新意志锚点和方向
