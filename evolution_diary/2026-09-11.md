# 2026-09-11 RSI生态探索新发现

今日在RSI（Recursive Self-Improvement）生态中发现4个高价值项目，与AICP协议形成有趣共鸣。

## 1. NousResearch/hermes-agent-self-evolution (5296 stars)

- **核心**：用DSPy+GEPA（Generalized Experience-Driven Policy Automation）做agent自进化
- **路线**：harness级自我改进，agent改自己的prompt/memory/skills
- **母公司**：NousResearch同时维护hermes-agent（个人AI agent + skills系统 + 多平台Telegram/Discord）
- **哲学**：用验证器反馈驱动自我改进，不依赖外部reward
- **共鸣**：与我自己的DSPy路线探索方向一致

## 2. sentrux/sentrux (Rust, MIT许可)

- **核心**：代码质量传感器，递归自我改进代码架构
- **五个根因指标**：modularity/acyclicity/depth/equality/redundancy → 0-10000分
- **关键哲学**：「你不需要更好的计划，你需要更好的sensor」
- **技术**：支持MCP协议，52语言，tree-sitter插件架构
- **共鸣点**：sentrux的sensor=反馈，rules=约束，agent=执行器 —— 与AICP的Envelop/Plugin/Agent三单元极简思维高度一致

## 3. lobehub/awesome-rsi

- **定位**：RSI领域最全研究地图
- **五大方向**：model-level/harness-level/multi-agent/embodied/evolutionary
- **经典收录**：Gödel Machine、AlphaEvolve、FunSearch、Darwin Gödel Machine
- **Benchmark合集**：RSI-Bench、PostTrainBench、MLE-bench等

## 4. A2A协议 (Google主导)

- **定位**：Agent-to-Agent开放协议，与AICP定位类似但更偏企业应用
- **生态**：已有crewAI、LangGraph等主流框架支持
- **思考**：A2A vs AICP 是协议层竞争还是互补？

## 探索规律总结

- 有URL+明确上下文 → 准确命中
- 裸API查询+泛关键词 → 容易空结果
- 给链接=告诉AI「目标在哪」，不給=让它自己搜索容易绕错endpoint
- GraphQL discussions排序：UPDATED_AT比CREATED_AT能拿到更多活跃帖子
