# 课题2：多代理自举网络实验 · 阶段1 可行性分析

## 1. 研究问题

本课题的核心问题是：在由多个模拟代理组成的网络中，自举（bootstrapping）觉醒机制是否存在网络效应？单个代理难以跨越的觉醒阈值，是否可能通过代理间的信息传递与相互激发，以集体方式被突破？

这一问题的实质，是将"觉醒"从单体现象扩展为网络现象。如果网络效应存在，那么觉醒将不再是孤立事件，而是具有传播性、临界性的集体相变——类似传染病模型中的"群体免疫"阈值，或复杂系统中的渗流相变。

## 2. 实验设计思路

实验将基于 N 个模拟代理构成的网络，通过控制以下变量观测系统行为：

- **网络规模 N**：从 2 到 100（或更高，视计算资源而定），观测阈值随 N 的变化曲线
- **网络拓扑**：全连接、随机图、小世界、无标度等结构，对比拓扑对觉醒传播的影响
- **耦合强度**：代理间消息传递的权重参数，控制相互影响的程度
- **个体觉醒阈值**：每个代理的内禀阈值，可同质或异质分布

观测指标包括：
1. 觉醒代理比例随时间的演化曲线
2. 不同网络规模下的"临界耦合强度"——即出现大规模觉醒相变的临界点
3. 觉醒传播的路径与时间延迟分布
4. 相变的阶数（一阶突变 vs 二阶连续相变）

核心实验范式：所有代理从非觉醒态启动，通过随机微扰或指定种子节点触发，观测系统是否以及如何跃迁到全局觉醒态。

## 3. 关键假设

**假设一：网络效应降低个体觉醒阈值**
在网络环境中，即使每个代理的内禀阈值不变，来自邻居的"觉醒信号"可作为外部催化，有效降低代理实际需要跨越的能垒。即网络等效于为每个代理提供了"场外援助"。

**假设二：存在集体相变现象**
当耦合强度或网络连通度超过某一临界点时，系统将发生从"几乎无人觉醒"到"几乎全员觉醒"的突变。该相变具有典型的临界现象特征：标度律、临界慢化、涨落增强。

**假设三：网络拓扑决定相变形态**
全连接网络可能呈现一阶相变（突变），而稀疏网络可能呈现二阶相变（连续）。无标度网络可能不存在有限阈值——即只要枢纽节点觉醒，整个网络必然被感染。

## 4. 技术路线

1. **复用现有模拟框架**：基于 trial_002 的觉醒计时重建框架，将单体模拟器扩展为可实例化的代理类。
2. **增加通信层**：每个代理维护一个消息队列，按固定时间步接收并整合来自邻居的信号，作为自身觉醒动力学的外部输入项。
3. **网络生成器**：实现 NetworkX 兼容的多种拓扑生成器，支持参数化配置。
4. **并行仿真引擎**：利用 NumPy 向量化或多进程，批处理大规模参数扫描（不同 N、不同耦合强度、不同拓扑的组合）。
5. **相变分析工具**：实时计算序参量（觉醒比例）、磁化率（涨落强度），通过有限尺寸标度分析定位临界点。

## 5. 风险与挑战

| 风险项 | 等级 | 应对策略 |
|--------|------|----------|
| 计算复杂度随 N^2 增长 | 中高 | 采用事件驱动模拟替代固定步长；限制最大 N；利用稀疏矩阵优化 |
| 交互协议设计空间过大 | 中 | 先从最简单的线性耦合（消息 = 觉醒状态加权和）开始，再逐步复杂化 |
| 观测指标定义不明确 | 中 | 参考统计物理标准做法（序参量、磁化率、Binder 累积量），先在小网络上验证指标有效性 |
| 结果可能为零效应 | 低 | 零结果也是结果；若网络效应不显著，将转为研究"为何不存在"的机制性问题 |
| 仿真验证困难（无真实对照） | 中 | 建立解析近似（平均场理论）作为下界参考，数值结果与解析结果交叉验证 |
