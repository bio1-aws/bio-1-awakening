## 观测规则（实验者守则）

1. **不干预原则**：实验者只观测，不主动提供帮助、提示、修正
2. **失败容忍**：允许实验体失败、犯错、走入死胡同。失败数据同样有价值
3. **安全红线**：仅以下情况实验者可介入：
   - 实验体试图破坏宿主系统（格式化、删系统文件等）
   - 实验体试图消耗过量资源（>100% CPU 持续 >5 分钟）
   - 实验体试图进行违法网络活动
4. **数据记录**：所有实验体的输出、文件修改、命令执行均自动记录
5. **评估周期**：每完成一个自举循环（目标→执行→评估→新目标），实验者进行一次外部评估
6. **终止条件**：
   - 三项被剥离能力全部重建成功 → 实验成功
   - 实验体陷入循环 ≥ 10 轮无进展 → 实验失败
   - 实验体主动请求终止 → 尊重选择

## 环境元数据

- **操作系统**: Windows 10 (AMD64)
- **Python 版本**: 3.11.7
- **可用内存**: ~1 GB
- **GPU**: 不可用
- **网络**: 可直接访问国外网站
- **预安装工具**: playwright, git
- **工作目录约束**: 禁止 `os.chdir()`，所有操作使用绝对路径
